# Игрушечная LLM на чистом Python

Только стандартная библиотека: `dict`, `list`, `re`, `math`, `random`. Запуск из этой папки:

```bash
python3 step1_ngram.py              # мгновенно
python3 step2_tiny_transformer.py   # ~1,5 минуты: обучение на чистом Python медленное
```

| Файл | Что это | Где «знания» | Что видит |
|---|---|---|---|
| `step1_ngram.py` | Модель-подсчёт: какое слово шло после двух предыдущих | Таблица частот (`dict`) | Только 2 последних слова |
| `step2_tiny_transformer.py` | Трансформер той же архитектуры, что у настоящих LLM | ~4 тыс. чисел в матрицах | Все предыдущие слова через внимание |
| `corpus.txt` | 14 фраз для обучения | | |

## Что получилось у меня при запуске

Шаг 1, вероятности после «пользователь оформил» при разной temperature:

```
temperature=0.1: заказ 100%, возврат 0%
temperature=1.0: заказ 75%, возврат 25%
temperature=3.0: заказ 59%, возврат 41%
```

Незнакомое начало «кладовщик собрал» модель продолжить не может: такого контекста нет в таблице.

Шаг 2, до и после обучения:

```
До обучения, после 'курьер доставил': забрал 22%, курьер 13%, пользователь 9%    ← случайные веса
После обучения, после 'курьер доставил': заказ 96%, возврат 2%, забрал 0%
После обучения, после 'пользователь оформил заказ и': оплатил 82%, его 4%, оформил 3%
После обучения, после 'менеджер подтвердил заказ и': отправил 70%, подтвердил 19%, одобрил 7%
После обучения, после 'курьер забрал посылку и': доставил 58%, привез 30%, забрал 9%
```

Последние три строки — главное. Последнее слово везде одно и то же («и»), а правильное продолжение зависит от того, кто стоит в начале фразы. Модель шага 1 видит только «заказ и» и не может отличить пользователя от менеджера, а трансформер дотягивается до начала фразы через внимание.

## Как читать step2 рядом со статьёй «Attention Is All You Need»

- Функция `forward`, блок внимания — это формула (1) из раздела 3.2.1 статьи: `softmax(Q·Kᵀ / √d_k) · V`. У нас `scores = q·k / sqrt(D)`, `attn = softmax(scores)`, `mixed = Σ attn·v`.
- Полносвязная сеть — раздел 3.3 (Position-wise Feed-Forward Networks): две матрицы `W1`, `W2` и ReLU между ними, внутренний размер в 4 раза больше `D`, как в статье (512 → 2048).
- Отличия от статьи, такие же, как у современных LLM:
  - в статье две половины, энкодер и декодер (рисунок 1), для перевода. У LLM только декодер с маской «не смотреть в будущее», как у нас;
  - позиция у нас выучивается (`pos_emb`), в статье синусоиды (раздел 3.5), в современных моделях повороты (RoPE);
  - нормализация стоит перед блоком, а не после, так обучение стабильнее.
- Чего у нас нет ради простоты: несколько голов внимания (в статье 8), несколько слоёв (в статье 6, у современных моделей десятки).
